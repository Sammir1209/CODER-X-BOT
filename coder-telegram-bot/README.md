# CODER Standalone Telegram Bot

Este directorio contiene el bot de Telegram de **CODER** (@CodexrOutBot) segregado y totalmente independiente de la aplicación principal.

## 🚀 Cómo ejecutar el Bot por separado

1. Asegúrate de tener instalado [Node.js](https://nodejs.org/).
2. Entra en esta carpeta e inicia el bot ejecutando:
   ```bash
   npm start
   ```

El bot se conectará mediante long-polling y gestionará las plantillas de autenticación y los comandos `/start`, `/register`, `/me` y `/help` con Emojis Custom de forma autónoma.
